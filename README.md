# Deep Learning Lab Assignments

This repository contains the lab assignments completed as part of the **Deep Learning coursework**. The assignments focus on implementing fundamental machine learning and neural network concepts such as perceptrons, regression models, backpropagation, and real-world deep learning applications.

---

## Lab Exercise 1 – Logic Gates using Perceptron
Design and implement a **perceptron model** to simulate basic logic gates.

Implemented gates:
- AND
- OR
- NAND
- NOR

Reference:  
https://www.enjoyalgorithms.com/blog/design-perceptron-to-learn-and-or-xor-gates

---

## Lab Exercise 2 – Logistic Regression (Glass Classification)

Implemented **Logistic Regression using a Single Layer Perceptron Neural Network (SLPNN)** to classify different types of glass.

Dataset:  
https://www.kaggle.com/datasets/uciml/glass

Reference:  
https://medium.com/analytics-vidhya/logistic-regression-using-single-layer-perceptron-neural-network-slpnn-31757c792d5d

---

## Lab Exercise 3 – Multiple Linear Regression using Perceptron

Implemented **Multiple Linear Regression** using a perceptron-based approach to predict outputs using multiple input variables.

Dataset:  
https://www.kaggle.com/datasets/hussainnasirkhan/multiple-linear-regression-dataset

---

## Lab Exercise 4 – Multilayer Perceptron (Backpropagation)

Implemented a **Multilayer Perceptron (MLP)** using the **backpropagation algorithm** to predict the **age of abalone** from physical measurements.

Dataset:  
https://archive.ics.uci.edu/dataset/1/abalone

---

## Lab Exercise 5 – Digit Classification

Implemented a **digit classification model** using neural networks to recognize handwritten digits.

---

## Lab Exercise 6 – Surface Defect Classification

Implemented a **deep learning model** to classify surface defects using image data, focusing on **Convolutional Neural Networks (CNNs)**.

Dataset:  
NEU Surface Defect Database

---

## Lab Exercise 7 – Electricity Consumption Forecasting

Built a **time-series forecasting model** to predict electricity consumption using deep learning techniques such as **LSTM/ANN**.

Dataset:  
Electricity Consumption Forecasting Dataset

---

## Lab Exercise 8 – Image Super Resolution

Developed a **deep learning model** to enhance image quality by increasing resolution using **super-resolution techniques**.

Dataset:  
Image Super Resolution Dataset
